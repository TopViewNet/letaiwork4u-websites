# LetAIwork4u Website Ecosystem

Vercel-ready Next.js prototype for:

- letaiwork4u.com
- handwerkervoicebot.de
- anwaltsoft.de
- bea4outlook.app

## Deploy on Vercel

1. Go to https://vercel.com/new
2. Import this project from GitHub, or drag/upload the extracted folder via your Git workflow.
3. Press Deploy.

## Local preview

```bash
npm install
npm run dev
```

Then open http://localhost:3000
